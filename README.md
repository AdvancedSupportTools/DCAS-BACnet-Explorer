Distech Controls BACnet Explorer is a powerful BACnet/IP & routed BACnet MSTP exploration utility with device discovery, object browsing, property reading/writing, priority handling, Out‑of‑Service control, CSV/log exporting, and an optional REST API panel.

Key Features:
- 3‑phase BACnet discovery (IP + routed MSTP)
- Object list loading and property reading
- Present‑Value write support with priority control
- Priority Array decoding
- Out‑of‑Service management
- Relinquish‑Default read/write
- CSV + Log exports
- Distech API Enhancements panel

Installation:
Windows 10/11
PowerShell 5.1+
Firewall must allow UDP BACnet ports

Usage Summary:
1. Launch BACnet Explorer
2. Select Network Interface
3. Run device discovery
4. Load object list
5. Read/write properties
6. Export devices/objects/logs
